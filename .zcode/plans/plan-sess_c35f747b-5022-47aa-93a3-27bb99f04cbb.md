基于OPENEDX-DEPLOYMENT-PLAN.md 14.6混合方案，将JupyterHub + Code-Server + PrairieLearn三个平台深度集成，打通账户体系和课程资源，补全全链路测试用例，并进行性能和压力测试。

## 第一阶段：修复现有问题 + 账户体系打通

### 1.2 JupyterHub功能增强
- **注册PrairieLearn评测API为JupyterHub服务**：在启动脚本中写入`autograder_url`环境变量和Python调用示例到学生PVC
- **增强nbgrader配置**：统一Exchange目录到`/home/jovyan/work/nbgrader/exchange`（当前配置指向`/srv/nbgrader/exchange`但实际数据在work目录）
- **增加课程-作业映射ConfigMap**：创建`cm-autograder-assignments` ConfigMap，包含每门课程的作业定义（题目、测试代码、评分标准），挂载到所有用户Pod

### 1.3 账户体系同步
- **从JupyterHub SQLite数据库读取所有用户**，生成统一的用户清单
- **创建用户同步脚本** `sync_users.py`：从JupyterHub DB读取用户列表，通过PrairieLearn API注册用户（ PrairieLearn autograder目前是无认证的，添加API Key认证）
- **统一课程映射**：JupyterHub的Lecture-P1~P6 → PrairieLearn的python-industrial课程；Lecture-B1~B6 → 暂无对应；Lecture-A1~A4 → 暂无对应

## 第二阶段：PrairieLearn Autograder增强

### 2.1 增强autograder_server.py
当前autograder仅支持Python基本评测。增强为：
- **多语言评测**：Python(pytest+pycodestyle)、Java(javac+junit)、Go(go test+gofmt)、Rust(cargo test+clippy)
- **作业管理API**：新增 `/api/assignments/create`（教师创建作业）、`/api/assignments/{id}/submit`（学生提交）、`/api/assignments/{id}/results`（查看成绩）
- **成绩报告**：`/api/report/{course_id}` 返回课程所有学生的成绩汇总
- **持久化**：将评测结果写入CockroachDB的`prairielearn`数据库（创建scores表）
- **API Key认证**：添加`X-API-Key`头认证，教师key和学生key权限不同

### 2.2 构建增强版镜像
- 基于现有`jupyterhub/custom:4.0.3`镜像，添加gcc/g++/default-jdk/golang/rustc
- 内置增强版`autograder_server.py`和`grader_runner.py`
- 推送到本地registry: `10.100.135.132:5000/prairielearn:v2`

### 2.3 创建CockroachDB评分表
```sql
CREATE TABLE IF NOT EXISTS scores (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    student_name STRING NOT NULL,
    course_id STRING NOT NULL,
    assignment_id STRING NOT NULL,
    score FLOAT NOT NULL,
    max_score FLOAT DEFAULT 100,
    language STRING NOT NULL,
    tests_passed INT DEFAULT 0,
    tests_total INT DEFAULT 0,
    lint_errors INT DEFAULT 0,
    feedback TEXT,
    submitted_at TIMESTAMPTZ DEFAULT now(),
    INDEX idx_course (course_id, assignment_id)
);
```

**B. Code-Server集成测试 (新增8项)**

**C. PrairieLearn评测测试 (新增10项)**
- 健康检查、课程列表、作业列表、Python代码评测(满分)、Python代码评测(有错)、PEP8 lint检查、成绩报告API、API Key认证、CockroachDB成绩持久化、多语言评测(Python/Java/Go/Rust各1项)

**D. 跨平台集成测试 (新增5项)**

### 3.2 性能和压力测试
**E. 性能基准测试 (5项)**
