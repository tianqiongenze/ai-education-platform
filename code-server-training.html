Security & Maintenance 安全与运维

🔒 零信任 NetworkPolicy

  • 默认拒绝所有入站流量
  • 仅允许 ingress-nginx → code-server
  • code-server → litellm (API 调用)
  • litellm → ollama-master (模型推理)
  • DNS 允许 (kube-system)

🔐 TLS/SSL 加密

  • code-server: HTTPS 已启用
  • Dify: HTTPS 已启用
  • 自签名证书 (内网环境)
  • ingress-nginx TLS 终止

🛠️ 故障排查

  • litellm 死锁: --num_workers 1
  • NetworkPolicy: 检查 pod 标签
  • 镜像拉取: 使用国内镜像源
  • NFS: systemctl start nfs-server

📋 运维命令

  • kubectl get pods -n ai-platform
  • kubectl logs -f deployment/code-server
  • kubectl describe hpa code-server
  • kubectl top pods -n ai-platform
